# 在真实 Mac 上验收

状态：待执行。Windows 的单元测试和界面验证不能替代以下硬件结果。

先在获授权的测试网络使用，只启用需要的检测。记录 macOS 版本、CPU 架构、网卡型号、Python 版本和应用提交号；不要记录凭据。

## 1. 安装与本机观测

- 从全新克隆执行 `bash scripts/install-macos.sh`，再启动；浏览器能打开工作台。
- 仅一条网线、仅一条 Wi-Fi 时分别启动；不要求第二接口，不出现虚假全网故障。
- 对照系统设置核对真实接口、IPv4、作用域网关和 DNS；`utun` / 回环不算物理网卡。
- 核对 CoreWLAN 的 SSID、BSSID、RSSI、信道和速率。系统不给 BSSID 时应显示未知，不猜 AP。记录实际隐私授权要求。
- 保存拓扑，退出重开确认配置保留；未检测状态不冒充正常。

## 2. 检测不能串路（发布门槛）

- 同时接入两条可区分路径，为同一测试服务分别配置接口和显式 DNS。
- 用测试端日志或抓包核对 DNS、TCP、HTTP、代理连接的出口，覆盖一条路径失败、另一条成功的情况。
- 拔掉指定网线，绑定检测不能借 Wi-Fi 变绿；可选接口暂停，必需接口异常。
- 测试域名无显式 DNS、IPv6 目标与指定接口 SSH：应为未知或明确不支持，不默认回退。
- 验证显式代理与 Mihomo 控制 API 是独立检测；API 返回 200 不等于代理可上网。

## 3. AP、休眠与事件

- AC 多 AP 的已核实 BSSID 清单：唯一匹配关联 AP，重复清单不强行选一个。
- 在 AP 间移动；保留接入变化事件，不改写用户声明的物理拓扑。
- 让测试服务连续失败达到阈值，仅生成一个待恢复事件；两次成功才恢复。
- 检测未知、Mac 休眠、换网或应用退出不能把旧故障写成已恢复；重启显示中断。
- 故障证据包含当时的接入信息和最近样本；SSH 失败仍保留本机证据。

## 4. 同一 Mac 的打印与 Minecraft

- Mac 节点同时有有线、Wi-Fi、USB，服务为打印共享和 Minecraft；不拆成两台 Mac。
- USB 打印机不填 IP，执行本机打印检测能看到 CUPS / USB 状态，队列只保存数量。
- 检测过程没有发送打印任务；手机发现与真实打印单独人工验证并记录协议兼容性。
- Java / Bedrock 用实际服务端各验证一次，核对版本与人数；停止测试服能产生协议失败。
- 本机资源与指定 PID 指标可查看；重启测试服务后核对 PID 和创建时间。不读取世界或聊天。

## 5. 凭据、诊断导出与常驻

- 钥匙串存取成功；拒绝访问时提示错误，无明文回退。拓扑导出不含凭据引用，导入检测禁用。
- 已知 SSH 主机可采集；缺公钥、公钥变化或认证失败必须拒绝，不新增信任。
- 不配置任何 AI 账号即可生成并下载 Markdown 和 JSON；导出不调用模型或上传报告。
- 用合成症状填写表单，核对两个文件的生成时间、站点、记录计数、重点故障及 UTC 时间线一致；下载后能被文本编辑器或 JSON 解析器读取。
- 导出包含全部仍保留记录，超过界面列表上限也不漏；跨站点不混入别处证据。未知/暂停/中断不算恢复。
- 检查凭据引用、常见密钥、私钥与 URL 查询秘密不出现在报告；网络标识仍保留，分享前人工确认。
- 旧快照没有历史拓扑时明确缺失，不拿当前拓扑当成历史；新快照保存当时拓扑。
- 安装用户登录项、退出登录后重进、查看状态、移除登录项；不影响已有打印或 Minecraft 服务。
