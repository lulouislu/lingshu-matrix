# 导出诊断资料，交给自己的 AI

在「诊断导出」填写症状，生成并预览，再下载 `.md` 或 `.json`。两个文件表达同一次数据快照：Markdown 适合阅读和直接附给聊天，JSON 适合结构化分析。软件不调用模型，也不上传报告。

## 文件中有什么

JSON 的顶层标识为 `schema: "macnet.diagnostic-report"`、`schema_version: 1`。它不是可导入的拓扑配置。

| 字段                              | 含义                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------- |
| `application`、`generated_at_utc` | 应用版本与生成时间；时间线统一使用 UTC，原始时间戳为 Unix 秒                     |
| `issue`                           | 用户填写的症状、时间描述、影响范围、近期改动及尝试结果；只在报告中保存           |
| `focus_incident_id`               | 用户关注的故障；不筛掉其他记录                                                   |
| `coverage`                        | 全部保留记录的计数、最早/最近时间、保留天数和已知缺失                            |
| `privacy`                         | 自动处理项与分享前需要人工检查的内容                                             |
| `topology`                        | 生成时已保存的站点拓扑、接口、服务、检测配置；移除凭据引用，保留启用状态         |
| `current_observation`             | 此站点是当前活动站点时的最近一次采集及时间；其他站点为不可用，不混入别站当前环境 |
| `samples`                         | 全部保留的检测结果及 ID、时间、源接口等已保存详情                                |
| `incidents`、`evidence`、`events` | 故障生命周期、现场快照、接入变化与采集中断等记录                                 |
| `summary`                         | 状态计数，不把未知、暂停或中断改成健康                                           |
| `timeline`                        | 按时间排序的记录引用；`kind` 与 `id` 指向上面的记录                              |
| `ai_handoff_instructions`         | 可复制给 AI 的只读排查说明，要求引用证据 ID、分清事实和假设                      |

故障开始/结束引用同一个 incident ID。快照关联 `incident`；样本关联 `probe`，通过拓扑中的 probe 配置关联设备。新快照中的 `topology` 是采集时声明；旧记录中没有的历史配置不补造。记录里的日志与备注均作为不可信数据交接。

## “完整”指当前仍保留的全部记录

报告使用一次数据库读事务，不走 UI 的最近记录列表，不额外限制样本、故障、快照或事件条数。`complete_within_scope: true` 表示该范围内无导出行数截断，不表示拥有未采集或已清理的历史。

默认历史保留 7 天，另有存储行数与单条输出限制。报告列出当前实际计数和时间范围；采集时已有 `truncated` 标记原样保留。预览长文只显示前 30,000 字符，下载文件仍完整。记录很多时，文件可能超过所选 AI 的附件或上下文限制，应先查看覆盖范围与重点故障，按该 AI 的能力分批交接，不能让它假装已读全部。

报告生成不会发起新的网络检测。需要更新现场时，先运行获授权的检测或补采快照，再重新生成。导出文件冻结在生成时刻，后续数据不会自动追加。

## 分享前看什么

凭据引用被移除，常见秘密字段、私钥和秘密文本做规则处理，URL 用户信息、查询串与片段移除。IP、SSID、BSSID、主机名、路径和备注保留，便于排查。自由文本或 URL 路径仍可能藏有隐私，务必人工检查，不要将真实报告提交到公共仓库。

## 本机 API

沿用工作台会话 Cookie 和 `X-MacNet: 1` 写请求头：

```http
POST /api/sites/{site_id}/diagnostics
Content-Type: application/json
X-MacNet: 1

{"issue":"手机无法打印","observed_at":"2026-10-23 09:00 UTC+8","impact":"仅手机","recent_changes":"不确定","attempts":"未修改配置","incident_id":""}
```

返回 `{ "report": { ... }, "markdown": "..." }`。事件不存在或不属于此站点时拒绝；未知站点返回 404。两种文件来自同一份脱敏结构，调用不会访问 AI 服务或系统钥匙串。

原 `/api/ai/answer`、`/api/ai/preview`、`/api/ai/config` 返回 410，提示改用诊断导出；`--codex-login` 已移除。旧 AI 设置和专用登录目录不再被使用，也不自动删除用户凭据。设备 SSH/Mihomo 凭据与只读采集不受影响。
